## 前言

Tailwind CSS 是一个功能优先的 CSS 框架，它提供了大量的工具类，让我们能够快速构建现代化的用户界面。在使用 Tailwind CSS 的过程中，我积累了一些实用技巧，在此分享给大家。

## 基础技巧

### 1. 使用 @apply 提取组件类

当某些工具类组合经常重复使用时，可以使用 `@apply` 提取为组件类：

```css
@layer components {
  .btn-primary {
    @apply px-4 py-2 bg-blue-600 text-white rounded-lg 
           hover:bg-blue-700 transition-colors duration-200;
  }

  .card {
    @apply bg-white rounded-xl shadow-md p-6 
           border border-gray-200;
  }
}
```

使用时更加简洁：

```html
<button class="btn-primary">点击按钮</button>
<div class="card">卡片内容</div>
```

### 2. 善用任意值

Tailwind CSS 支持任意值语法，可以处理特殊的设计需求：

```html
<!-- 任意宽度 -->
<div class="w-[342px]">精确宽度</div>

<!-- 任意颜色 -->
<div class="bg-[#1da1f2]">Twitter 蓝</div>

<!-- 任意间距 -->
<div class="mt-[37px]">特殊间距</div>
```

### 3. 使用 group 实现父元素悬停效果

```html
<div class="group cursor-pointer">
  <img class="group-hover:scale-105 transition-transform" src="image.jpg" />
  <h3 class="group-hover:text-blue-600 transition-colors">标题</h3>
  <p class="group-hover:text-gray-700 transition-colors">描述文字</p>
</div>
```

## 暗色模式

### 1. 基本配置

首先在 `tailwind.config.mjs` 中启用暗色模式：

```javascript
export default {
  darkMode: 'class',
  // ...
}
```

### 2. 使用 dark: 前缀

```html
<div class="bg-white dark:bg-gray-900">
  <h1 class="text-gray-900 dark:text-white">标题</h1>
  <p class="text-gray-600 dark:text-gray-400">正文内容</p>
</div>
```

### 3. 主题切换实现

```javascript
// 切换暗色模式
function toggleDarkMode() {
  const html = document.documentElement;
  html.classList.toggle('dark');
  
  // 保存用户偏好
  const isDark = html.classList.contains('dark');
  localStorage.setItem('theme', isDark ? 'dark' : 'light');
}

// 初始化时读取偏好
if (localStorage.getItem('theme') === 'dark' ||
    (!localStorage.getItem('theme') && 
     window.matchMedia('(prefers-color-scheme: dark)').matches)) {
  document.documentElement.classList.add('dark');
}
```

## 响应式设计

### 1. 移动优先原则

Tailwind CSS 采用移动优先的设计策略：

```html
<!-- 默认是移动端样式 -->
<!-- sm: 640px 以上 -->
<!-- md: 768px 以上 -->
<!-- lg: 1024px 以上 -->
<!-- xl: 1280px 以上 -->
<!-- 2xl: 1536px 以上 -->

<div class="grid grid-cols-1 sm:grid-cols-2 lg:grid-cols-3 gap-4">
  <!-- 卡片 -->
</div>
```

### 2. 响应式排版

```html
<h1 class="text-2xl sm:text-3xl md:text-4xl lg:text-5xl font-bold">
  响应式标题
</h1>

<p class="text-sm sm:text-base md:text-lg leading-relaxed">
  响应式正文内容，确保在不同设备上都有良好的阅读体验。
</p>
```

### 3. 隐藏和显示元素

```html
<!-- 仅移动端显示 -->
<div class="block md:hidden">移动端菜单</div>

<!-- 仅桌面端显示 -->
<div class="hidden md:block">桌面端导航</div>

<!-- 不同断点显示不同内容 -->
<span class="block sm:hidden">手机</span>
<span class="hidden sm:block md:hidden">平板</span>
<span class="hidden md:block">电脑</span>
```

## 自定义主题

### 1. 扩展默认主题

在 `tailwind.config.mjs` 中添加自定义配置：

```javascript
export default {
  theme: {
    extend: {
      colors: {
        primary: {
          50: '#eff6ff',
          100: '#dbeafe',
          200: '#bfdbfe',
          300: '#93c5fd',
          400: '#60a5fa',
          500: '#3b82f6',
          600: '#2563eb',
          700: '#1d4ed8',
          800: '#1e40af',
          900: '#1e3a8a',
        },
      },
      fontFamily: {
        sans: ['Inter', 'system-ui', 'sans-serif'],
        mono: ['JetBrains Mono', 'monospace'],
      },
    },
  },
}
```

### 2. 使用 CSS 变量

结合 CSS 变量实现更灵活的主题系统：

```css
@tailwind base;

@layer base {
  :root {
    --color-primary: 37 99 235;
    --color-background: 255 255 255;
    --color-text: 31 41 55;
  }

  .dark {
    --color-primary: 96 165 250;
    --color-background: 17 24 39;
    --color-text: 229 231 235;
  }
}
```

```javascript
// tailwind.config.mjs
export default {
  theme: {
    extend: {
      colors: {
        primary: 'rgb(var(--color-primary) / <alpha-value>)',
        background: 'rgb(var(--color-background) / <alpha-value>)',
        text: 'rgb(var(--color-text) / <alpha-value>)',
      },
    },
  },
}
```

## 实用技巧

### 1. 文本截断

```html
<!-- 单行截断 -->
<p class="truncate">这是一段很长的文字...</p>

<!-- 多行截断 -->
<p class="line-clamp-2">这是一段很长的文字，需要截断显示...</p>
<p class="line-clamp-3">这是一段很长的文字，需要截断显示三行...</p>
```

### 2. 自定义滚动条

```css
/* tailwind.config.mjs */
plugin(function ({ addUtilities }) {
  addUtilities({
    '.scrollbar-thin': {
      'scrollbar-width': 'thin',
      '&::-webkit-scrollbar': {
        width: '6px',
        height: '6px',
      },
      '&::-webkit-scrollbar-track': {
        background: 'transparent',
      },
      '&::-webkit-scrollbar-thumb': {
        background: 'rgb(156 163 175 / 0.5)',
        'border-radius': '3px',
      },
    },
  });
});
```

```html
<div class="overflow-auto scrollbar-thin">
  <!-- 长内容 -->
</div>
```

### 3. 玻璃效果


## 性能优化

### 1. 使用 JIT 模式

Tailwind CSS v3.0+ 默认启用 JIT 模式，只生成实际使用的 CSS。

### 2. 清除未使用的样式

在生产环境中，Tailwind 会自动清除未使用的样式：

```bash
npm run build
```

### 3. 使用 CDN 快速原型

```html
<script src="https://cdn.tailwindcss.com"></script>
```

> 注意：CDN 版本仅用于开发和原型设计，生产环境应使用正式安装方式。

## 最佳实践

1. **保持一致性**：使用主题配置的颜色和间距，避免硬编码数值
2. **移动优先**：先写移动端样式，再用响应式前缀添加桌面端样式
3. **组件提取**：重复使用的样式组合应该提取为组件类
4. **语义化命名**：自定义类名要有意义，如 `.btn-primary` 而非 `.blue-btn`
5. **合理使用 @apply**：不要过度使用，保持 Tailwind 的灵活性
